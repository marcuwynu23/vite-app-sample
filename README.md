## Features

- Lightning-fast development server with Hot Module Replacement (HMR)
- Optimized production builds
- Framework-agnostic and extensible

## Getting Started

### Prerequisites

- Node.js 14+
- npm or yarn

### Installation

```bash
npm install
```

### Development

```bash
npm run dev
```

The app will be available at `http://localhost:5173`

### Build

```bash
npm run build
```

### Preview

```bash
npm run preview
```
